# Ecommerce Text Classification

This project performs product category classification for e-commerce product descriptions using Natural Language Processing (NLP).

## Features
- TF-IDF Vectorization
- Multinomial Naive Bayes Classification
- Text preprocessing using spaCy
- Lemmatization
- Stopword and punctuation removal
- Comparison of:
  - Without preprocessing
  - With preprocessing

## Technologies Used
- Python
- Pandas
- scikit-learn
- spaCy

## Dataset
Dataset: Ecommerce Text Classification Dataset

Categories:
- Electronics
- Household
- Books
- Clothing & Accessories

## Workflow
1. Load dataset
2. Apply TF-IDF vectorization
3. Train Multinomial Naive Bayes model
4. Evaluate using classification report
5. Perform preprocessing using spaCy
6. Retrain and compare results
